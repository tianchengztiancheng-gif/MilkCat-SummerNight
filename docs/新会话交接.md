## 二、已经定下来的事

- **授权**：天青作者已授权使用 Larimar 的代码、素材链接、设定、开局、提示词。署名写在 `NOTICE`；天青的内容不适用 MIT。
- **剧本格式叫 `<MilkCat>`**（块：`MilkCat_maintext / _branches / _snapshots / _hook / _variables`）。
  天青原来的 `<summernight>` 和 juus 的 `<Gal>` 都继续兼容。格式细节见 README 和 `core/milkcat.js` 文件头。
- **角色做成内置角色包**（`packs/<id>/`）：包里只放内容 + 配置；角色独有的玩法做成「机制模块」，包在配置里启用。
  改玩法只改模块一处。一次游戏一个主角包 + 若干客串包。
- **代码底子**是从 gal 引擎 v5.27 复制来的（不是在 Larimar 上改），所以多人同台、存档树、记忆、文生图、手机端都是现成的。

## 三、怎么跟用户协作（重要）

- 用户说中文，回复要简洁、直接，少术语。
- **git 提交 / 推送由用户自己用 GitHub Desktop 做**，不要替他 commit / push。改好的文件放进 `D:\photo\超级奶猫` 就行。
- **在用户电脑上别跑会写 git 索引的命令**（`git status` 会留下 `.git/index.lock`，GitHub Desktop 会提示仓库被锁）。
  要看状态用 `GIT_OPTIONAL_LOCKS=0`，或只用 `git log`、`git config --get`、`git ls-files` 这类只读命令。
  真留下了锁：请求删除权限，只删 `.git/index.lock`。
- 往用户文件夹写东西前，先比对一下文件有没有被用户改过（比 md5），别覆盖用户的改动。
- 导出 / 存档 / 日志里不能出现 API 密钥；NovelAI token 只发给 NovelAI。
- 不要运行别人预设里的酒馆助手 JS 脚本（会把密钥交出去）。
- 别人的角色卡 / 预设 / 素材不进仓库（`.gitignore` 已挡；天青包是授权的例外）。
- juus 版（`D:\photo\gal`）是另一个项目：用户在别的对话里维护，这里不要动它，除非用户明确要求。

## 四、开发环境要点（云端工作区）

- 云端看不到 `huggingface.co`、`catbox.moe`、`github.io`（代理拒绝），真图加载不了。截图检查时用 Playwright 拦请求、
  给每种图返回带文字的占位 SVG（参考 `tools/e2e-milkcat.mjs` 的路由写法）。
- Playwright：`chromium.launch({ executablePath: '/opt/pw-browsers/chromium' })`，别 `playwright install`。
- 冒烟测试要 jsdom：`npm i jsdom@^26 --no-save`。
- 用户电脑上（device_bash）有 node，可以直接跑单测：`node tools/unit/run-all.mjs`。
- 新加 core 文件时，记得同时加进 `index.html`（带 `?v=`）和 `tools/smoke-test.js` 的 `FILES` 列表。
- 每次发版改 `index.html` 里所有 `?v=mc…` 版本号（GitHub Pages 缓存 10 分钟，新旧文件混用会报错）。
